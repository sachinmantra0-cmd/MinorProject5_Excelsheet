# 📊 Excel Minor Project – Sales Operations Analytics

An interview-style **Data Analytics project using Microsoft Excel** to analyze sales operations for a multi-category retail business. The project focuses on data cleaning, lookup functions, conditional aggregation, PivotTables, and advanced Excel analysis to derive meaningful business insights from raw sales data.

## 📌 Project Overview

This project simulates a real-world sales analytics scenario where an analytics team is given multiple raw datasets and asked to answer business questions before a leadership review.

The project contains data from:

* 🛒 Orders
* 👥 Customers
* 📦 Products
* 👨‍💼 Sales Representatives
* 🎯 Monthly Sales Targets

The analysis is organized into five major sections, covering **100 marks of interview-grade Excel analytics tasks**.

## 🎯 Objectives

The main objectives of this project are to:

* Analyze sales and revenue data
* Perform data lookups across multiple worksheets
* Identify and diagnose data-quality issues
* Calculate business metrics using conditional aggregation
* Build and analyze PivotTables
* Compare sales performance against targets
* Rank sales representatives based on revenue
* Perform advanced multi-condition analysis
* Extract actionable business insights using Excel

## 🔎 Analysis Performed

### 1. Lookup Functions

The project uses multiple Excel lookup techniques, including:

* `VLOOKUP`
* `INDEX + MATCH`
* Two-way lookup
* Nested/chain lookups
* Approximate-match lookup
* Self-join lookups

Examples include finding customer IDs, product names, sales representative names, product categories, sales targets and team-lead information.

### 2. Data Cleaning & Quality Diagnostics

The project identifies common real-world data-quality problems such as:

* Duplicate orders
* Leading/trailing whitespace
* Inconsistent city capitalization
* Broken customer references
* Orders containing discontinued products
* Suspicious payment/discount patterns

### 3. Conditional Aggregation

Business metrics are calculated using functions such as:

* `SUMIFS`
* `COUNTIFS`
* `AVERAGEIFS`
* `SUMPRODUCT`
* Nested `IF` / `IFS`
* `LARGE`

The analysis includes revenue by city, discount and payment status analysis, customer-segment analysis, top-performing sales representatives and sales-target performance.

### 4. PivotTable Analysis

PivotTables are used to analyze:

* Sales region vs. product category
* Monthly revenue by sales representative
* Percentage contribution by category
* Quarterly revenue
* Profit margins
* Cross-sheet sales performance

### 5. Advanced Excel Analysis

Advanced techniques include:

* `RANK.EQ`
* Running/cumulative totals
* `TEXTJOIN`
* `LARGE`
* `INDEX/MATCH`
* Multi-condition Top-N analysis
* Maximum-value analysis
